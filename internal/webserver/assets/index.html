One farm. A clearer view.

This dashboard shares the existing BambuStand monitoring session. It refreshes every three seconds while visible, and best-effort while hidden when browser notifications are enabled. Suspended or closed pages cannot deliver notifications. Stop the monitoring process to stop the server. In terminal mode, you can also disable Web Server in Config (,). Closing browser tabs leaves monitoring running.

The server listens only on 127.0.0.1 and has no authentication. Other programs and users on this computer can read display data and hide notices locally. Keep it local; remote access is not supported. For a terminal-free synthetic demo, run bambustand serve --demo; use bambustand serve for cloud-backed monitoring after saving a login.

The Filament tab shows per-unit reported drying status and remaining minutes. Missing values stay unknown; old readings are last-known. Drying settings describe configuration, and the original AMS has no active dryer. Monitoring cannot start or stop drying.

Filters and sorting preserve your printer selection as updates arrive. The Active filter includes printers last reported as running, independently of availability. The Idle filter includes only currently available online printers explicitly reporting Idle or Finished. Offline, stale, missing, and unknown states are excluded; a finished job does not establish that the build plate is clear. Search matches printer names and models. Each status count reflects that search independently of the selected status. On narrow screens, use the Status selector. Cards start collapsed; use the small footer chevron to expand inline readings or collapse them again. Expansion choices last for this page session, including updates, filtering, sorting, and resizing. Keyboard expansion and collapse keep the focused footer in view. If resizing hides the focused chevron or Details button, focus moves to that printer name. If resizing hides Details while inspection is open, closing returns focus to the printer name. Desktop shows full cards. Attention and unavailable-data warnings remain visible when collapsed; the printer name opens Overview.

Scrolling the farm compacts the header. The filter, search, and sort toolbar stays beneath it once reached. Return to the top to expand the header. In small workspaces, the toolbar scrolls with the cards to keep them reachable.

Sorting always places online non-idle printers first, reported idle or finished printers next, and offline devices last. Name, Attention, or State ordering applies within each group. Unknown states stay outside idle for ordering only; stale readings remain last-known.

Status counts can overlap: attention and availability may overlap reported print states. Clear search to restore whole-farm counts.

Printer names, job names, and normalized telemetry appear here. Credentials, raw payloads, account information, and printer serial identifiers are excluded.

Overview groups the reported job, progress, time estimates, layers, and nozzle/bed/chamber temperature tiles. Expand Reading details for independent report and estimate times. Finish estimates stay anchored to the remaining-time report; paused and other non-running states have no running finish estimate. Unknown progress stays unknown, and old readings remain last-known. Offline inspection omits job, temperature, and inventory readings; notices remain reachable.

In Filament, select an AMS or external slot to inspect its material, color, presence, and quantity inline. Selection is local inspection, not a reported nozzle assignment. Empty, zero estimate, unknown, and unavailable remain distinct. A removed selected entry stays unavailable instead of selecting another slot. External quantity is unavailable. Reopening clears selection.

Printer inspection has Overview, Filament, and Notices tabs. Printer names and Details open Overview; attention actions and notification clicks open Notices. Empty results offer Clear search and Show all statuses when applicable. Use Left/Right, Home/End on the tabs, then Tab to enter the scrolling panel. Tabs and Close stay visible; opening reveals the selected tab. Updates keep your tab, focus, and reading position. Closing returns to the same printer action when it remains visible.

Inspecting a condition does not acknowledge, hide, snooze, or physically resolve it. Hide a notice locally here; terminal mode also offers acknowledgement, snooze, and restoration. Demo decisions are session-only. Use the printer or Bambu's applications for physical intervention.

Overview and Notices share a print outcome with consolidated next steps. Verified cancellation says Task canceled while preserving raw FAILED; only reported FINISH confirms completion. Individual notices and local decisions stay separate. Last-known outcomes cannot confirm current state or physical repair. Description coverage does not change notification policy.
